Database structure consists of the following tables:-
trains: Information on trains with the primary key TrainID.
users: Information on user accounts made, primary key is userID.
arrivalschedule: Arrivals with trainIDs, timings and stations.
departureschedule: Departures with trainIDs, timings and stations.
ticket: Booked tickets unique to every user.

The files contain the functioning programs along with HTML files for the three webpages as well as the site style. It can be used to log in or register, and book tickets.
